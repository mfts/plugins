# Set up pstack

Follow the [plugin README](../../README.md) to install this host's port. Start with the **setup-pstack** skill to configure role models and reasoning budget. Defaults inherit the current session; setup only writes explicit models confirmed as available.

Use **poteto-mode** for a real engineering task. It chooses the matching playbook and loads relevant principles and supporting skills. Use **create-verification-skill** when the project needs a harness that drives real behavior.

Read the [platform guidance](../../PLATFORM.md) for delegation, history, scheduling, and tool availability. Cursor-only APIs are not supplied by these ports.
